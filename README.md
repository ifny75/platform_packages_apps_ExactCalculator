## ✨ Overview

**ExactCalculator** is a straightforward Android calculator focused on making everyday calculations feel effortless. Its uncluttered interface keeps the essentials in reach, balancing simplicity, usability, and precision.

This repository is a fork of the calculator maintained by **GrapheneOS**, with roots in the Android Open Source Project.
